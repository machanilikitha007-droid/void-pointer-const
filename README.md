# Void Pointer with const Data

## Author
M.Likitha

## Description
This program demonstrates using a const void pointer
to access data without modifying it.

The function receives the address through a const void
pointer and converts it into a const int pointer.

## Concepts Used
- Void pointer
- const void pointer
- Type casting
- Dereferencing
- Read-only data access
- Functions

## How to Run

gcc void_pointer_const.c -o void_pointer_const

./void_pointer_const
